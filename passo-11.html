O Jejum Como Espaço Para Deus

Jejum como prática de dependência

📖

Para Começar

Chegamos a uma prática que, para muitos, é a mais desconhecida: o jejum. Jejuar não é sobre punir o corpo ou merecer algo de Deus. Jejum é criar espaço — abrir mão de um apetite legítimo para dizer que Deus é maior que nossa fome imediata.
